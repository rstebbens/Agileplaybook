# Coaching Playbook

A collection of practical Agile coaching tools, posters and visual guides from [robstebbens.com](https://robstebbens.com).

These resources are designed to be used, shared and adapted by teams, coaches and anyone trying to make work work a little better.

## Free resources

The resources in this repository are provided for personal and professional use under the licence included with each resource.

Use what helps. Ignore what doesn't. Adapt the rest.
